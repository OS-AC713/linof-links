# linof-links
A service to ensure you don't get confused and always know the official links—plus, it doesn't use normalization.


> Please note that this utility will later be transferred as a command to the os-core713 terminal. To avoid losing it, here's a link to the project: https://github.com/OS-AC713/os-core713. This utility will be called linof, which stands for "Links Of." This utility provides official links to services. If you need more, please let me know in the issues which service you'd like to add.
